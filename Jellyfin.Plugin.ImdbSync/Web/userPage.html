How do I get my IMDb cookie?
  1. Open imdb.com in a desktop browser and sign in.
  2. Press F12 to open the developer tools and switch to the Network tab.
  3. Reload the page (F5) and click the first request (www.imdb.com).
  4. Under Request Headers, copy the whole value of cookie and paste it above.

Alternative: Application (Chrome) / Storage (Firefox) tab → Cookies → https://www.imdb.com → copy the values of at-main (starts with Atza| or Atna|) and session-id.

The cookie gives access to your IMDb account. It is stored only on this Jellyfin server and is never shown again after saving. If you sign out of IMDb in the browser, the cookie stops working and you need to paste a new one.
